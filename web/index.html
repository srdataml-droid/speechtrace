SpeechTrace preserves audio for review in your browser. The open-weight models run on a free-tier hosted service with usage limits. Recording is sent to Groq Whisper only with your consent and a configured API key. Transcript and measured features go to a Groq-hosted open-weight coach only with separate consent. Server API handlers do not intentionally persist your recording; providers may apply their own retention policies. Automatic transcripts and coaching recommendations can be wrong. SpeechTrace is a rehearsal guide, not a psychological or emotion detector.
